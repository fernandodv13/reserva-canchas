# Sistema de Reserva de Canchas Deportivas

Proyecto personal desarrollado para practicar arquitectura full-stack.

## Stack
- Backend: Node.js, Express, MongoDB Atlas
- Frontend: Angular

## Estructura
- `/backend` -> API REST (modelos, rutas)
- `/frontend` -> Aplicación Angular

## Funcionalidades
- Autenticación de usuarios (roles: admin / cliente)
- Gestión de canchas (CRUD, solo admin)
- Reserva de canchas por horario
- Reportes de ocupación
